# 惯性观测驱动的角色姿态模块

用多个可穿戴惯性传感器的**方向观测**（或陀螺+加速度原始数据）驱动一个
人形角色姿态。核心约束：**绝不把传感器上报的四元数直接赋给骨骼**，而是
经过显式标定把传感器坐标映射到骨段，再在父子骨架层级下求解满足关节关系
的姿态。

## 图形入口（主要使用方式）

惯性姿态的主要入口是**角色捕捉视窗**，一个仅依赖 Python 标准库的本地 Web
应用（无需 Tk/显示器/前端框架）：

```bash
python3 -m inertial_pose.capture            # 默认 http://127.0.0.1:8000/
python3 -m inertial_pose.capture --port 8123
```

浏览器打开后可在同一页面完成：

- **观测轴向切换**：模拟传感器换绑，仅允许行列式 +1 的正当轴置换；
  选择镜像反射（det −1）等非法重排时，后端显式报错并在页面顶部异常区
  呈现，而不是静默退化为恒等变换。
- **回放**：播放/暂停、拖动进度条、循环、0.25–2× 变速、视角偏航与自动旋转。
- **结果区**：3D 骨架姿态、每个骨段的**惯性偏差**（最终 FK 朝向相对惯性
  观测的真实角度残差）、累计足滑、足锁-航向**仲裁事件**、标定残差与世界
  参考航向，以及关节角/根位置对照指标。
- 可注入观测噪声、随机安装偏置、运行期航向漂移，并调节足滑/航向仲裁权重。

所有展示数值都来自真实的标定与求解计算；链路异常（非法轴向、未标定传感器、
越界参数）统一以 `{"ok": false, "error": ...}` 返回并在视窗异常区显示。

## 命令行（仅辅助）

CLI 只做无界面批处理辅助，交互与可视化请用上面的捕捉视窗：

```bash
python3 -m inertial_pose.cli calibrate --action walk          # 标定残差核验
python3 -m inertial_pose.cli run --action walk --drift-rate 0.12 --out pose.json
python3 -m inertial_pose.cli sweep  --action walk             # 漂移×权重扫描
python3 -m inertial_pose.cli bias   --action walk             # 观测噪声扫描
```

另有等价的脚本封装：`scripts/generate_synthetic.py`、
`scripts/run_bias_sweep.py`。

## 三个严格分开的坐标框架

| 框架 | 含义 | 对应量 |
| --- | --- | --- |
| 传感器框架 S | IMU 芯片自身正交轴 | 观测 `q_WS` |
| 世界/导航框架 W | 重力 + 磁力/外部航向定义，每传感器可有独立航向 | 世界参考 `world_yaw`（`q_W0W`） |
| 骨段框架 B | 骨架 rest pose 定义的规范局部轴 | 安装旋转 `q_BS` |

完整可核验链路（见 `inertial_pose/calibration.py`、`inertial_pose/solver.py`）：

```
q_WS (观测)
  → q_W0W (世界参考修正，独立航向量)
  → q_BS  (标定安装旋转)
  → q_W0B (骨段世界朝向)
  → 父子层级 → 关节局部旋转
  → 关节自由度投影/角限位
  → 最终姿态 + 足锁/航向仲裁
```

安装旋转、世界参考、骨架局部轴始终是三个独立量，不合并成一个四元数。

## 可观测性与显式先验

- 单个静止 IMU 无法分离安装旋转与世界航向（二者以乘积耦合）；重力确定
  倾斜，磁力/外部航向确定偏航。因此标定**要求显式提供 `world_ref_yaw`**。
- 方向数据**不唯一确定平移**。根位置来自显式先验：落脚瞬间建立足锁锚点，
  支撑段锁定；无锚点动作（举臂）退回固定根高度，不宣称方向能恢复平移。
- 未观测关节使用显式静止先验（单位局部旋转），只恢复可由观测确定的自由度。

## 足锁与航向冲突仲裁

惯导航向漂移与已落地足锁矛盾时，在同一帧显式比价两条路线并取代价小者：

- **修正航向**：保留锚点，代价为躯干航向跃变角（`jump_weight`）；
- **释放锚点**：跟随惯导航向，代价为假设足滑弦长（`slide_weight`）。

支撑相由**大腿相对骨盆的俯仰 + 滞回**判定（足部旋转率在平面步态中恒为
零，不可用）；新锚点需连续若干帧摆动确认才重建，避免支撑段误判在漂移点
重置。捕捉视窗与 `cli sweep` 可直接观察权重如何翻转决策。

## 坐标约定

Z 轴向上、角色面向 +X、左侧为 +Y；髋/膝/踝等矢状面铰链绕局部 **y** 轴，
运动发生在 x-z 平面；左右腿的横向分离完全由髋部 rest 偏移承担，两侧使用
同构的局部铰链角度（镜像来自平移而非旋转符号）。

## 测试

```bash
python3 -m pytest tests/ -q
```

测试的求解器输入**只有**合成传感器观测 `q_WS`；真值骨段旋转仅用于标定
样本与最终指标，不存在绕过标定直接驱动角色的路径（见
`tests/test_driver_pipeline.py` 的结构性断言）。
